# Verify FixAm

FixAm is Next.js 16 + Drizzle + Supabase, pnpm. All commands run from the repo root (`D:\xampp\htdocs\FixAm`).

## Standard gate (run in order, fix failures before committing)

```powershell
pnpm typecheck   # tsc --noEmit
pnpm lint        # eslint — warnings are tolerated, errors are not
pnpm test        # vitest run — ~351 unit tests
pnpm build       # next build — must compile all ~136 routes
```

Run `pnpm build` before pushing anything that touches routes, layouts, `app/`, `components/`, `lib/`, or `globals.css`/`*.css`. Typecheck+lint+test are enough for isolated lib changes.

## Database migrations

- New migrations live in `drizzle/NNNN_name.sql` (generated by `pnpm db:generate`, hand-editable).
- Apply to the live Supabase DB with:
  `node scripts/apply-sql.cjs drizzle/NNNN_name.sql`
  (uses `DATABASE_URL_DIRECT || DATABASE_URL` from `.env.local`; idempotent only if the SQL is — most aren't, so don't re-run blindly.)
- Verify applied objects with `node scripts/check-migrations.cjs`.
- CI has **no Supabase env vars** — never create a Supabase client at module/render scope in code reachable by public routes (see `components/auth/auth-methods.tsx` for the on-demand pattern).

## Conventions that break checks

- Escape apostrophes in JSX text as `&apos;` (`react/no-unescaped-entities`).
- Files must be UTF-8; Windows-encoded dashes in docs break lint diffs.
- After every change: update `docs/CHANGELOG.md` (and `docs/DECISIONS.md` / `docs/devin-spec/specs/*.json` when behaviour, routes, schema or env vars change).
- Commit AND push to `origin/main` when done (user rule in AGENTS.md).

## E2E (optional, needs running app)

```powershell
pnpm test:e2e        # playwright test
pnpm inngest:dev     # Inngest dev server for background jobs
```

Playwright e2e is not part of the standard gate — run it only when touching auth flows, payments, or scheduled jobs.
